# 하모길

**진주에서, 교통약자가 "여기서 저기까지 내 몸으로 갈 수 있는가"를 묻는 앱.**

경상국립대 AI Pioneer 캠프 2차 (2026-08-06~07) · 주제 3번 고령자·교통약자 · 팀 프로젝트.

---

## 왜 만들었나

무장애 정보를 주는 서비스는 이미 여럿 있다. 그런데 대부분 **"어디가 좋은가"(장소)** 를 알려 준다.
정작 필요한 건 **"여기서 저기까지 내 몸으로 어떻게 가는가"(경로)** 다.

그리고 하나 더 — 기존 서비스는 **아는 것만 보여 준다.**
모르는 정보는 화면에서 그냥 사라진다. 그러면 쓰는 사람은 "없다"와 "모른다"를 구별할 수 없다.

하모길은 **모르면 모른다고 쓴다.**

## 확신도 — 이 앱의 핵심 규칙

앱 안의 모든 정보에는 확신도가 붙어 있다.

| 표시 | 뜻 | 조건 |
|---|---|---|
| ✅ 확인됨 | 출처를 대고 말할 수 있다 | 출처 필수 |
| ⚠️ 추정 | 근거는 있으나 직접 확인 못 함 | 근거 명시 |
| 🟠 제보됨 | 이용자가 알려 줬고 아직 검토 전 | 검토 대기 |
| ❓ 모름 | 모른다 | 값은 비워 둔다 |

**❓를 ✅처럼 보이게 만들지 않는다.** 지어내지 않는다. 이것이 이 앱이 다른 서비스와 다른 점이다.

## 정보 제보

모르는 칸은 이용자가 채울 수 있다. 다만 **바로 반영되지 않는다.**
제보하면 증빙 자료와 함께 검토를 거친 뒤 ✅로 올라간다. 검토 전에는 🟠로 표시된다.

## 만든 방식

- 빌드 도구 없음. HTML + CSS + 바닐라 자바스크립트뿐.
- `index.html`을 브라우저로 열면 그대로 돌아간다.
- 번역만 예외 — 배포한 뒤에만 작동한다 (`/api/translate`).

## 직접 돌려 보기

1. 이 폴더를 내려받는다.
2. `index.html`을 더블클릭한다.

끝이다. 설치할 것이 없다.

## 폴더

```
index.html      화면 뼈대
css/style.css   디자인
js/data.js      정보 (확신도 포함)
js/app.js       화면 전환
js/search.js    검색
js/detail.js    상세
js/result.js    경로 결과
js/report.js    제보
js/i18n.js      한국어/일본어/영어
api/translate.js  번역 프록시 (서버)
```
